# Мелкие грабли агента

Временный журнал мелких трудностей окружения и нюансов (терминал, кодировки, таймауты, пути Windows и т.п.).
Не путать с `cursorcontext.md` — туда переносим только повторяющиеся (≥5) и важные для долгосрочной памяти.

## Правила ведения

1. При столкновении с мелкой проблемой — добавить запись или увеличить `Счётчик`.
2. Рядом писать краткое **Решение** (команда / приём / workaround).
3. Когда `Счётчик` достигает **5** — перенести описание + решение в `cursorcontext.md` (раздел «Грабли окружения»), здесь оставить пометку `→ перенесено в cursorcontext` и архивировать запись.
4. Не писать сюда продуктовые баги, roadmap и секреты.

Формат записи:

```
### Краткий заголовок
- Счётчик: N
- Симптом: …
- Решение: …
- Дата первого раза: YYYY-MM-DD
- Дата последнего раза: YYYY-MM-DD
```

## Активные

### bun.exe на Windows не отвечает и грузит CPU
- Счётчик: 1
- Симптом: `bun --version` и установщик зависают без вывода. Несколько процессов `bun.exe` поднимают загрузку CPU до 100%, после этого перестают отвечать и другие команды
- Решение: `bun.exe` не запускать. Зависимости ставить через `npm install`, сервер — `npm run dev`. В `vite.config.ts` хост `127.0.0.1`, иначе Vite слушает только `[::1]`
- Дата первого раза: 2026-10-29
- Дата последнего раза: 2026-10-29
